Select runners to ready up.

Each selected runner must use this app and ready the same roster. Ready expires after 45 seconds without a heartbeat. Uncheck to start with runners who are not using this app. One shared server-clock start controls every countdown; this does not start or pause the games.

Room countdowns are followed automatically by default. A server “Starting countdown of Ns” announcement uses the selected runners and bypasses app ready checks. A saved start is never replaced; choose a new session for another race. Change automatic following in Settings.

Keep at least one connected timer running until everyone finishes. Minimize this app to keep recording. Closing it stops recording. Times use live goal receipt and the room’s clock, so network delay affects precision. A goal missed by every timer shows “Time unavailable”; it is never assigned a guessed finish time. Longest BK is the longest gap without a recorded check, including start to first check and last check to finish. Group BK measures gaps with no checks from any selected runner. Times finalize when the runner or group finishes.

Checks are recorded during this timed run only. Duplicate locations and checks after release or completion are excluded. Late joins, connection gaps and older runs may have incomplete check history; BK is based on recorded events. Automatic collect can also generate checks for other worlds and cannot always be distinguished from play.
