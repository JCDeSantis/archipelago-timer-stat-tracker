# Feature ideas

History, linked usernames, alert preferences, finish cards, connection health,
race profiles, countdown sounds, result preview and race highlights are now
available; see [Race tools](RACE_TOOLS.md). The list below preserves the original
ideas, including follow-up work within those areas.

1. **Saved race history.** Keep a local library of runs with seed, roster, times,
   check counts, releases and BK results, with incomplete recordings clearly marked.
2. **Alert preferences.** Choose which event types appear, their optional sounds,
   and whether alerts cover your runner, everyone else, or the whole group.
3. **Personal-best comparisons.** Compare against a previous comparable run and
   show the time difference beside the clock or in the final results.
4. **Custom splits.** Add named, manually triggered milestones for each game and
   compare individual split times after the race.
5. **Check-pace graph.** Plot recorded checks over time and show a rolling
   checks-per-minute rate for individuals and the group.
6. **BK summary.** Report the number of long gaps, total time in those gaps,
   longest BK, and when each gap started and ended in the recorded timeline.
7. **Finishing-order board.** Show completed runners in time order, with released
   runners clearly separated so a release is never presented as a race win.
8. **Shareable finish cards.** Export a PNG with the race name, individual or group
   time, checks and BK highlights, ready to share manually.
9. **Local OBS browser overlay.** Offer a stream layout with configurable
   background, clock, event alerts and optional runner standings.
10. **Race profiles.** Save a preferred layout, roster and alert preferences,
    while using a fresh session name for a new run and keeping passwords unsaved.
11. **Countdown audio and cancellation.** Add optional start sounds and a shared
    countdown-cancel action that reaches every connected timer before play begins.
12. **Connection and recording health.** Show reconnect periods, last server
    activity, and gaps where check counts or event times may be incomplete.
13. **Timeline replay.** Scrub through a saved race's recorded events and check
    activity to review stalls, bursts of checks and the finish sequence.
14. **Organizer view.** Provide a larger dashboard for watching the roster,
    readiness, recorded check progress and active BK gaps during a group race.
15. **Break markers.** Let runners label a planned break in the timeline without
    pausing the race clock, so post-run BK reviews have more context.
16. **Item handoff board.** Let runners manually flag what is blocking progress
    and mark a request resolved when their teammates can help.
17. **Configurable shortcuts.** Add shortcuts for splits, switching views and
    opening stats without reaching for the mouse.
18. **Appearance presets.** Save clock fonts, colors and display density in
    Settings so users can tune a stream or race layout themselves.

Suggested next additions: personal-best comparisons, custom splits, check-pace
graphs, then an OBS overlay. A shared countdown-cancel action remains separate
from the optional countdown audio already available.
